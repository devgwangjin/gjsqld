# 🧅 SQLD 합격 기원!

> **SQLD(SQL 개발자) 자격증 단기 합격을 위한 나만의 기출 풀이 & 오답노트 웹앱**  
> 🌐 **배포 사이트**: [https://gjsqld.vercel.app](https://gjsqld.vercel.app)

---

## 🎯 주요 기능

* **기출 900제 수록**: 제45회부터 제62회까지 18개 회차 기출 복원 문제 전수 수록
* **2024 개정 교재 핵심 개념 연계**: 문제 풀이 시 단원별 핵심 비교표와 요약 카드 자동 매핑
* **원터치 즉시 채점**: 1~4번 버튼 터치 시 즉시 O/X 채점 및 해설 노출 (Active Recall)
* **오답노트 & 헷갈림(별표) 자동 누적**: 틀린 문제만 모아 무한 반복 학습 가능
* **반응형 멀티 디바이스 지원**: PC, 태블릿(아이패드/갤럭시탭), 모바일 환경 최적화
